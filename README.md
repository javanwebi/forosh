# Forosh — Business Workspace

A mobile-first, Persian RTL business management app with configurable workspaces for different shop types.

## Stack
- React + Vite
- JavaScript
- CSS with responsive layouts
- Local demo data and browser persistence for the first MVP

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

This first scaffold is a frontend MVP. Authentication, database persistence, payment, and AI automation are intentionally left for later phases.
